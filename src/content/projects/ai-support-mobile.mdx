## Key Capabilities

- **Real-Time Inbox Sync**: Socket.IO connection manager with dynamic reconnect, room joins, and unread badge counters.
- **Multi-Channel Admin**: Single interface managing conversations across WhatsApp, Telegram, and Instagram channels.
- **Workspace Analytics & Assignment**: Mobile UI for viewing agent assignment status, workspace analytics, and channel configurations.
