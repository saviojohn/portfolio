## Key Capabilities

- **Camera QR Check-In / Out Flow**: Modal camera scanner reading embedded pass payloads and executing automatic check-in/check-out timestamping.
- **Thermal Receipt Printing**: Branded receipt generation customized for standard 80mm thermal printer output using `@react-pdf/renderer` and `react-to-print`.
- **Dynamic Items Security Pass**: Outpass creation supporting dynamic multi-item arrays with validation for items leaving facility grounds.
- **Excel Audit Export**: Client-side Excel log exporter using SheetJS for security audit compliance.
