## Key Capabilities

- **Address Book Management**: Full CRUD address manager with optimistic UI updates and GTM telemetry (`add_address`, `remove_address`).
- **Wishlist Telemetry Sync**: Synchronized wishlist state across product grids, detailed views, and GTM tracking (`add_to_wishlist`).
- **Profile Avatar Uploads**: Multipart image upload pipeline via `react-dropzone` with CDN integration.
- **Invoice PDF Blob Downloads**: Blob-based client invoice PDF downloader handling dual guest and authenticated session headers.
