## Key Capabilities

- **Session & Auth Coordinator**: Handles JWT renewal with single-flight locking to prevent concurrent API calls from triggering duplicate auth refresh cycles.
- **Real-Time Wallet & Rate Updates**: Socket.IO integration for live updates to wallet balances, exchange rates, and ongoing transfer statuses.
- **Bi-lingual Localization**: Dynamic runtime switching between English and Japanese across 1,200+ UI strings.
- **Secure File & Identity Uploads**: S3 presigned URL upload flow for identity verification documents (KYC).
