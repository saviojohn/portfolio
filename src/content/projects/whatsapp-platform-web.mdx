## Key Capabilities

- **Meta WhatsApp Template Builder**: Multi-component builder supporting dynamic headers, footers, CTAs, button URLs, character count rules, and live mobile preview.
- **Send Template Direct**: Inbox integration allowing agents to browse, populate dynamic variables, and dispatch approved templates to re-open expired 24-hour messaging windows.
- **Bulk Campaign Validation**: Dynamic CSV/Excel recipient parsing with country code cleaning, carousel card options, and estimated campaign cost calculation.
